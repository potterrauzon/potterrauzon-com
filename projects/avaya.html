Avaya Self-Service Admin Portal

A self-service admin portal for Avaya's cloud communications. There were dozens of dense telecom tasks to account for, and the team worked them into one shell with a small set of patterns used over and over, carried across roughly ninety screens.

Design System Enterprise UX Web App
// Details
ClientAvaya
RoleVP Product Design
Timeline2019
Scope~90 screens

The trouble was size. Running an Avaya deployment means users, permissions, telephony, ordering, billing, monitoring, and support, and not one of those is simple. Left alone it turns into ninety pages that have nothing to do with each other. So we built a system instead of a pile of screens: one shell that never moves, a serif display face over a plain working sans, and Avaya red kept back for a single job so it means something when it shows up.
